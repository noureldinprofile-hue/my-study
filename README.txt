# Student Study Website

A responsive, bilingual (Arabic-first / English) website for downloading your own study PDFs.

## Add your original PDFs
Put your existing files in the `pdfs` folder and rename them exactly:
- Arabic PDF: `study-ar.pdf`
- English PDF: `study-en.pdf`

The website does not create, rewrite, or replace your study. The download buttons link to those two files.

## Run locally
Open `index.html` in a browser. For more reliable local testing, use VS Code with the Live Server extension.

## Publish online
Upload the contents of this folder to a static host such as GitHub Pages, Netlify, or Cloudflare Pages. Keep the `pdfs` folder and its filenames unchanged.
